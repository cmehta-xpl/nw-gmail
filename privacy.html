nw-gmail privacy policy

Last updated: 9 October 2026

Who uses it

nw-gmail is a personal tool used only by its owner, with the owner's own Google accounts. No one else signs in to it.

What it accesses

With the owner's consent, it requests access to the owner's Gmail (reading, creating drafts, and adding or removing labels), Google Calendar (read only) and Google Contacts (read only).

Where data goes

Data is fetched to, and used on, the owner's own computer. Sign-in tokens are stored there, encrypted. nw-gmail runs no server, keeps no copy of anyone's data elsewhere, and does not sell, share or transfer Google user data to anyone.

Google API Services User Data Policy

nw-gmail's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
